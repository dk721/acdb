    О системе

    Сервер написан шизоидом-гентушником-сишником-лентяем-идиотом и просто хорошим человеком

    И всё-таки

    Сайт работает на сервере написанном на чистом си, взаимодействующий с unix socket api для обработки соединений, postgresql для работы с базами данных, openssl для шифрования (да скорее всего вы подключены по HTTP протоколу и сеть не защищена, но ваши пароли хранятся в виде хэш-суммы).

    А ещё стили работают через tailwind cdn, так что потребуется подключение к интернету. (Уже нет, скрипт теперь передаётся с этого сервера)

    Почему сайт так стилизован?

    Моей ограниченной фантазии хватило сил только спародировать тему из сайта emacsdocs.org, когда нибудь я всё же осилю этот редактор.
